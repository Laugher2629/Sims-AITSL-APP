# Standards Made Explicit

A small web tool that makes each AITSL Graduate Teacher Standard explicit as **What to do** and **How to check**, with a checklist, status tracking, evidence notes and a subject-tagged resource library.

Built from the design in my EDST8040 Task 1 project proposal.

- Progress is saved in your own browser (localStorage). Nothing is uploaded.
- Use **Export my progress** to back up or move to another device, and **Import** to restore.
- Standards wording is a plain-language summary. Official descriptors: https://www.aitsl.edu.au/standards
